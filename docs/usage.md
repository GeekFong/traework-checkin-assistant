# 使用指南

本文档是面向最终用户的详细说明，面向开发者的内容见 [README](../README.md) 与 [项目结构](../README.md#项目结构)。

## 这个工具是做什么的

帮你每天自动领取 TraeWork CN / 腾讯 WorkBuddy 的登录积分，无需自己记得打开客户端签到。

- 一键手动签到、每天定时自动签到（关机错过会在开机后自动补签）
- 多个账号批量签到，两个平台账号统一管理
- 账号可随时停用 / 启用，不删除也能临时不签到
- 签到结果推送到个人微信 / 企业微信群 / 钉钉群
- 自动保存近 90 天签到历史：连续天数、成功率、月度统计、14 天明细、90 天热力日历、积分趋势图，可导出 CSV
- 一键备份 / 恢复全部本地数据，可导出脱敏诊断包
- 网络异常自动重试、失败账号多轮重试、掉线预警、防假成功校验、健康自检
- 每周一 / 每月初自动发送周报 / 月报
- 浅色 / 深色主题

## 使用前提

1. Windows 10 / 11（64 位）
2. 已安装 TraeWork CN 或腾讯 WorkBuddy 客户端，并且至少登录过一次
3. 普通用户权限即可，无需管理员

## 第一次使用

1. 双击 `TraeWorkCheckin.exe`。
2. 出现蓝色“Windows 已保护你的电脑”时，点击“更多信息 → 仍要运行”（程序未购买收费数字签名，不是病毒）。
3. 窗口顶部选择平台（TraeWork CN 或 WorkBuddy）。
4. 状态显示绿色“环境正常，已登录”即可签到；显示未登录则点“打开并登录”，在客户端登录后工具会自动识别；提示找不到客户端时点“手动选择程序位置”。
5. 点击“立即签到”，看到“签到成功，获得积分”或“今日已签到”即正常。
6. 建议在“每日自动签到”区域确认时间（默认 09:00）并点击“开启 / 更新签到时间”。

自动签到有两道触发：每天设定时刻 + 登录 Windows 后约 3 分钟补检。运行前会先核对今天的签到历史，已全部成功则立即退出，一天开关机多次也不会重复签到或推送。实际触发会在设定时间上随机延后 0–5 分钟。任务每次触发都会先推送一条「开始签到」通知（无论到点执行还是开机补签，每天至多一条；即使当日已全部签到也会发这一条报平安），若确有账号需要签到，完成后再推送当日结果日报。

## 多个账号批量签到

两个客户端同一时刻只能登录一个账号，工具把每个账号的登录凭证加密保存成“快照”，签到时逐个直接调用官方接口，不需要客户端保持登录。

添加账号：

1. 在客户端登录第一个账号，工具确认“已登录”。
2. 点击“保存当前 TraeWork 账号”或“保存当前 WorkBuddy 账号”。
3. 在客户端切换第二个账号，识别后再次保存；重复直到全部加入。

使用：

- “全部账号签到”立即对全部已保存账号（两个平台一起）签到。
- “备注”按钮可设置“主力号”等别名，显示在列表、结果、推送、历史与 CSV 中。
- 橙色“重登”按钮在登录失效时打开客户端并给出分步引导。
- “参与签到”勾选框可临时停用账号，凭证保留、随时恢复。
- 有账号失败时自动再重试 2 轮，只重试仍失败的账号；登录失效类失败不参与重试，直接给重登引导。

安全说明：快照凭证使用 Windows DPAPI 加密，绑定当前电脑和 Windows 账户，复制到其他电脑或换账户均无法解密，明文不写盘。令牌过期会自动用刷新令牌续期并回写；刷新令牌也失效时重新登录并保存一次即可。

## WorkBuddy 凭证读取顺序

1. 优先读取桌面端明文凭证：`%LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth\workbuddy-desktop.info`（正被写入时自动重试）。
2. 不存在时降级读取 VS Code 版 CodeBuddy 扩展的加密凭证，通过 Windows DPAPI + AES-GCM 解密。

两种方式都无需手动操作。

## 推送配置

### Server酱（推荐）

1. 打开 <https://sct.ftqq.com>，微信扫码登录并关注“方糖”服务号。
2. 在 SendKey 页面复制 `SCT` 开头的 Key。
3. 工具内勾选“开启微信推送”，渠道选 Server酱，粘贴 Key，保存。
4. 点“发送测试消息”验证。免费版每天 5 条，多账号汇总成一条，完全够用。

### PushPlus

<https://www.pushplus.plus> 扫码登录后复制一对一推送 token；注意需完成实名认证才有额度。

### 企业微信群机器人

1. 群“右上角 ... → 群机器人 → 添加”，复制 Webhook。
2. 安全设置选“自定义关键词”，填 `签到`（消息标题必含此词）。
3. 渠道选企业微信群机器人，粘贴完整 Webhook 或 `key=` 后的串，保存并测试。

### 钉钉群机器人

1. “群设置 → 机器人 → 添加机器人 → 自定义”，复制 Webhook。
2. 自定义关键词同样填 `签到`。
3. 粘贴完整 Webhook 或 `access_token` 的值，保存并测试。

勾选“仅在有账号失败时推送”后，全部成功的日子不发消息。Key/Webhook 以 DPAPI 加密保存（仅本机当前用户可解密），界面上会直接回显当前生效的凭据，方便核对；输入框留空保存则沿用原凭据。

## 历史与统计

- 今日概况：今天几个账号成功 / 共几个账号
- 每个账号连续签到天数、近 30 天成功率（≥90% 绿、50–89% 黄、<50% 红）
- 最近 3 个自然月月度统计
- 近 14 天逐日明细：✓ 成功、✗ 失败、⚠ 成功但待人工确认
- 90 天热力日历：绿=全部成功、黄=部分成功/待确认、灰=无记录、红=全部失败
- 30 / 90 天积分趋势折线图，每账号一条颜色线
- “推送记录”窗口查看每次推送的渠道、时间、成败与失败原因
- “导出 CSV”生成 Excel 可直接打开的 UTF-8 表格：日期、星期、平台、账号、结果、类型、积分、时间、说明

历史超过 90 天自动清理；只打开界面不执行签到不会产生历史记录。

## 备份、恢复与诊断包

- **备份数据**：把账号快照、推送设置、签到历史、推送记录打包成 zip。凭证密文绑定本机账户，换机后需重新登录。
- **恢复数据**：选择备份 zip 还原；已有同名文件自动转存 `*.restore-bak`，恢复不对时把 `.restore-bak` 改回即可。
- **导出诊断包**：只含账号数量、平台分布、历史概况、系统信息、最近日志与崩溃记录；账号名打码、密钥只显示前 2 字符加 `***`、凭证只标注是否存在，绝不含明文。
- **换机迁移向导**：历史卡片右上角“换机迁移”，按 4 步引导操作；新机器上必须逐账号重新登录并重新保存推送 Key。

## 数据文件位置

默认在 exe 所在文件夹；不可写时自动切换到 `%LOCALAPPDATA%\TraeCheckinApp\`。可用环境变量 `TRAESIGN_HOME` 指定自定义数据目录。

| 文件 | 内容 |
| --- | --- |
| `accounts.json` | 多账号快照（凭证密文） |
| `settings.json` | 推送设置（密文）与主题 |
| `checkin_history.json` | 签到历史 |
| `push_history.json` | 推送记录 |
| `period_markers.json` | 开始签到 / 周报 / 月报发送标记 |
| `trae_checkin.log` | 运行日志（1MB 轮转，3 份） |
| `crashes/` | 崩溃转存（最多 10 份） |

把工具发给别人时**不要**连同这些 json 一起发。

## 稳定性机制

- 超时 / 429 / 500–504 自动重试最多 3 次，1-2-4 秒退避；领取结果不明确时主动回查。
- 网络错误翻译为中文提示：超时、DNS 故障（可改 223.5.5.5）、未联网、代理失败、证书校验失败、限流等。
- 静默任务单次最多运行 30 分钟，失败每 10 分钟重试、最多 3 次。
- 全局异常钩子兜底主线程、后台线程与 Tk 回调；崩溃写入 `crashes/`，下次启动提示。
- 高级环境变量：`TRAESIGN_NO_JITTER=1` 关闭抖动；`TRAESIGN_FORCE=1` 忽略“今日已签”；`TRAESIGN_OFFLINE_DAYS=N` 掉线阈值。

## 常见问题

**Q：双击没反应 / 一闪而过？**
稍等几秒；仍无界面查看日志，或检查杀毒软件是否拦截。

**Q：微信收不到推送？**
先点“发送测试消息”：Key 是否完整、是否关注“方糖”、免费额度是否用尽；检查是否勾选“仅失败时推送”。

**Q：自动签到没执行？**
确认设定时间前后开过机（开机会补跑）、程序显示“已开启”；触发有 0–5 分钟随机延后。

**Q：出现“待人工确认”？**
服务器返回成功但核对不到积分变化，请打开客户端确认；持续出现多为官方接口改版，需要更新工具版本。

**Q：提示“上次运行异常退出”？**
选“是”导出诊断包后清除，选“否”直接清除，选“取消”保留记录下次再问。

**Q：杀毒软件报风险？**
未签名个人程序的常见误报，可信任 / 允许；也可用源码自行审计打包。
